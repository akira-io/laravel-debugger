## [1.0.0] - 2025-10-25

### Added

- Initial release of Akira Debugger
- Laravel 12+ support exclusively
- PHP 8.4+ strict typing throughout
- Query debugging with N+1 detection
- Slow query monitoring
- Duplicate query detection
- Mail debugging and mailable inspection
- Event tracking and monitoring
- Job execution tracking
- HTTP client request/response logging
- Cache operation monitoring
- View rendering debugging
- Exception tracking with full context
- Rector integration for automated refactoring
- Laravel Pint for code formatting
- Larastan level max static analysis
- Pest testing framework
- 100% type coverage
- Modern PHP 8.4 features (readonly properties, typed constants, attributes)
- PSR-12 compliant code style
- Comprehensive test suite
- CI/CD with GitHub Actions
